Мощный инструмент Android для управления приложениями и разрешениями, работающий на базе Shizuku.

Разрешения

Полный контроль над разрешениями Android, включая скрытые, для защиты вашей конфиденциальности.

На Shizuku

Используйте мощь Shizuku для продвинутых операций без получения Root-прав с высокой эффективностью.
